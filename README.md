# 리센느 00초 가이드

러스챗(플러스챗) 리센느 선착순 신청을 **정확히 00초에** 누르도록 도와주는 웹페이지입니다.
폰·PC 브라우저에서 그대로 열면 됩니다. 설치 필요 없음.

## 여는 법
- **권장(폰·PC 공통):** 무료 정적 호스팅에 올려 주소(URL)로 접속.
  1. GitHub 계정에서 새 저장소를 만들고 이 폴더 파일을 올립니다.
  2. 저장소 Settings → Pages → 브랜치 지정 → 나오는 주소를 폰·PC에서 즐겨찾기.
  - (원하면 도와드립니다.)
- **주의:** `index.html`을 더블클릭해서 여는 방식은 브라우저 보안 정책 때문에 동작하지
  않습니다(시계가 멈춰 보임). 반드시 주소(http://)로 접속하세요.
  PC에서 임시로 쓰려면 터미널에서 이 폴더로 이동 후 `python3 -m http.server 8765`를
  실행하고 `http://127.0.0.1:8765`로 접속하면 됩니다.

## 쓰는 법 (v2)
핵심 원칙: **00초 전에 도착하면 최후순위**, 조금 늦는 건 손해가 작다 → 정각이 아니라
**"정각 + 안전 여유"에 서버 도착**을 목표로 맞춥니다.

1. 페이지를 열고 "시계 동기화됨"을 확인합니다.
2. **⚡ 자동 보정 시작** → 실전과 똑같이 트랙패드를 꾹 누르고 있다가 "삐"에 맞춰 뗍니다.
   8초 간격 5번 → 리드타임 자동 적용 → 확인 3번 → "✅ 준비 완료"(약 1분 반).
   네트워크 지연·시계도 자동으로 잽니다.
3. **공지의 기입 항목을 체크리스트 칸에 붙여넣고** 🎬 리허설을 1번 해봅니다.
4. 실전 10분 전에 자동 보정을 한 번 더 → 가이드 창과 러스챗 창을 나란히 두고,
   폼을 다 채운 뒤 제출 버튼 위에서 꾹 누르고 대기 → "삐"에 뗍니다.

## 참고
- 표준시 = 리센느 서버시간(측정으로 확인). 특별한 경우가 아니면 "수동 보정값"은 0으로 둡니다.
- 웹 버튼은 누를 때가 아니라 **뗄 때** 실행됩니다. 그래서 "누르고 있다가 떼기"가 실전과 같은 동작입니다.
- 맥 설정 → 트랙패드 → "강한 클릭 및 햅틱 피드백"은 꺼 두세요(세게 누르면 다른 기능이 작동).
- 블루투스 이어폰은 소리가 늦게 들립니다. 보정과 실전은 같은 소리 장치로 하세요.
